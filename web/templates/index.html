Threat Intelligence

Understand the local and optional online intelligence layers powering PhishGuard.

LOCAL ENGINE

LAYER 01

Machine Learning

A locally trained Random Forest classifier evaluates numerical URL features and estimates phishing probability.

Model loaded locally
⌘
LAYER 02

Local Threat Rules

Heuristic checks identify suspicious URL characteristics, including IP-based hosts, unusual symbols and suspicious keywords.

Rules available offline
⚑
LAYER 03

Threat Lists

Local blocklist and allowlist files provide offline domain intelligence. If API keys are configured in the project .env file, Google Safe Browsing and URLhaus are also queried for known malicious URLs.

Local lists enabled
